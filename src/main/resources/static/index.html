    Help

    Blueprint is an AI-powered multi-cloud FinOps platform that combines ETL-driven billing analytics with autonomous AI agents.

    • Trace AI Agent: Ask natural language questions about your cloud spend. Trace autonomously generates validated SQL queries using Google Gemini and returns plain-English answers.
    • Predictive Forecasting: Generate cost forecasts using a scikit-learn linear regression model trained on your historical billing periods.
    • Audit Engine: Run automated anomaly detection powered by a dedicated microservice that scans for duplicate charges across billing records.
    • Organization Context (RAG): Upload markdown files describing contracts, policies, and team ownership so Trace can reason with company-specific knowledge via vector embeddings.

    For the full architecture and technology breakdown, open the info page.
