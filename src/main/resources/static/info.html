Blueprint

Multi-Cloud FinOps Platform: Fast, scalable cost analytics for enterprise cloud billing.

Ready to explore?
Overview

Blueprint is evolving into a cloud billing intelligence workspace. The dashboard combines billing analytics, Trace-assisted FinOps investigation, organization-specific context files, predictive modeling, audit workflows, and planned Athena-style querying for deeper cost analysis.

Key Features
  • ●
    Trace FinOps assistant
    Ask billing questions, explore optimization prompts, and connect answers to company context.
  • ●
    Organization Context
    Upload markdown files for contracts, policies, ownership, and tenant-specific FinOps guidance.
  • ●
    Forecasting & Audit Engine
    Predictive cost estimates and audit actions are surfaced directly in the dashboard.
  • ●
    Athena-ready query workflow
    The UI is prepared for governed analytical queries over billing data, beyond fixed filters.
Quickstart
  1. Open the Dashboard and select help on the top left for guidance.
  2. Next, select Load Dummy Data. This loads a predefined cloud billing CSV dataset.
  3. Ask Trace about cost drivers, policy fit, savings opportunities, or executive summaries.
  4. Add Organization Context markdown files so Trace can reason from tenant-specific knowledge.
  5. Review predictions, audit actions, and the planned Query Billing Data module for deeper analysis.
