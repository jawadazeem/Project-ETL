Overview

Blueprint is an AI-powered cloud billing intelligence platform. It combines autonomous SQL generation via Google Gemini, scikit-learn cost forecasting, automated anomaly detection, and retrieval-augmented generation (RAG) with organization context to turn raw multi-cloud billing data into actionable insights.

Key Features
  • ●
    Trace AI Agent
    Autonomous natural language to SQL pipeline powered by Google Gemini. Ask questions in plain English and get validated PostgreSQL queries, executed results, and AI-generated answers.
  • ●
    Predictive Cost Forecasting
    scikit-learn LinearRegression models trained on historical billing periods to forecast future cloud spend with trend visualization.
  • ●
    Automated Audit Engine
    Python-based anomaly detection microservice that scans billing records for duplicate charges and cost irregularities across cloud providers.
  • ●
    Organization Context (RAG)
    Upload contracts, policies, and ownership documents as markdown. Trace uses PGVector embeddings to ground its answers in your organization's specific context.
Quickstart
  1. Open the Dashboard and click Load Dummy Data to ingest a multi-cloud billing dataset spanning three billing periods.
  2. Ask Trace a question like "What are the top 5 most expensive services?" and watch it generate, validate, and execute SQL autonomously.
  3. Run Predictive Forecasting to see historical charges and ML-generated cost projections.
  4. Trigger the Audit Engine to scan for duplicate charges and billing anomalies.
  5. Upload Organization Context documents so Trace can reason with your contracts, policies, and team ownership data.
